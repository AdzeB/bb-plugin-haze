# Theme examples artwork

The fourteen scene builders in this directory are copied without changes from
Anthropic's `theme-examples` plugin, commit
`b5b01ac4f889fec0c4c6bb89f27ca7c8574473f6` (2026-11-14).

Source: https://github.com/anthropics/claude-plugins-official/tree/b5b01ac4f889fec0c4c6bb89f27ca7c8574473f6/plugins/theme-examples

They are licensed under Apache License 2.0; see [LICENSE](LICENSE).
`index.ts` adapts their builders to Haze. `../../scene-catalog.ts` adapts
the upstream names, descriptions, color schemes, tint colors and twin names.

The rest of Haze is covered by its root MIT license.
